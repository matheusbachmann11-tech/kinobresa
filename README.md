# 🧀 Kinobresa — ERP de Gestão de Laticínios

Sistema ERP para gestão de laticínios desenvolvido em **Firebird 4.0**, com controle completo de produção, estoque, vendas e rastreabilidade por lote.

## 📌 Funcionalidades

* Cadastro de fornecedores e matéria-prima
* Controle de produção por lote
* Produtos com custo e preço de venda
* Controle de estoque por movimentação
* Cadastro de clientes
* Pedidos de venda
* Nota fiscal vinculada ao pedido
* Rastreabilidade completa da produção

## 🔁 Fluxo do Sistema

Fornecedor → Matéria Prima → Produção → Produto → Estoque → Pedido → Nota Fiscal

## 🗄️ Estrutura

Principais tabelas:

* TB_FORNECEDOR
* TB_MATERIA_PRIMA
* TB_PRODUCAO
* TB_PRODUTO
* TB_ESTOQUE
* TB_CLIENTE
* TB_PEDIDO
* TB_PEDIDO_ITEM
* TB_NOTA_FISCAL

## 🚀 Tecnologias

* Firebird 4.0
* SQL
* Generators
* Foreign Keys
* Índices de performance
